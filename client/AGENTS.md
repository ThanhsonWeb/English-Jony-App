# StudyJony dialogue generation

Default Codex workflow for a new topic: **generate Dialogue/Story JSON → validate JSON → author and validate contextual glossary → prepare thumbnail manifest and prompts**. Stop there and tell the user the manifest is ready to give to ChatGPT.

For every new Dialogue or Story draft, include `metadata.contextualGlossaryVersion: 1`. After the final English lines and Vietnamese translations are saved, automatically run `npm run glossary:prepare -- <courseId> <dialogueId>` from `client`. Read the generated `glossary-prompt.txt` and `glossary-template.json`, then use Codex to author `glossary.json` beside `draft.json`, following the existing lesson glossary schema. Review all word occurrences and useful expressions against both languages; preserve individual word meanings, reuse entries only for the same sense, and put useful grammar/context explanations in optional hidden notes. Run `npm run glossary:check -- <courseId> <dialogueId>` before preparing thumbnails or reporting the draft complete. Preparation creates mappings and an authoring request, not translations. Neither runtime nor builder may call a translation API. Never automatically rewrite an approved glossary or bulk-create glossaries for old lessons. The builder validates before promotion and publishes a new glossary only when none is already approved.

1. Run `npm run dialogue:thumbnails:prepare -- <courseId>` from `client` after the final JSON files are ready. The helper validates each dialogue and writes `generated/<stories|dialogues>/<courseId>/thumbnail-manifest.md` plus a `thumbnail-prompt.txt` for each dialogue, using the course config's `contentType`. Fix any JSON validation failure before reporting the manifest ready.
2. Review the manifest for the dialogue slug, title, real speakers, scene/context, important visual details, background/time of day, and consistent StudyJony style. Use the real dialogue text and existing character/style references. Give the user the manifest path and say it is ready for ChatGPT to generate one separate slug-named PNG per dialogue.

**Do not generate thumbnail images in Codex, even when an image-generation tool is available.** Do not call image-generation tools or spend Codex quota on thumbnails. ChatGPT handles image generation separately. `dialogue:build` still handles promotion and audio; it does not generate images.
