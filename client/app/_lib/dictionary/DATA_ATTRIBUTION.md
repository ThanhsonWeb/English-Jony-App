# Local dictionary data attribution

`dictionary.json` contains a compact, normalized subset derived from the
[Skypedia English-Vietnamese Dictionary](https://github.com/skypediacode/english-vietnamese-dictionary).
The subset prioritizes common English words using StudyJony's existing frequency
list, keeps one learner-facing meaning and pronunciation per word, and includes a
small number of manually clarified common meanings.

The source dictionary was created and maintained by Skypedia and is derived from
the MinhQND Dictionary project and other open linguistic resources documented in
the source project's attribution file.
